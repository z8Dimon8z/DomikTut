`database-schema.md`

Если используется SQLite, обязательно нужен файл, где описано:

- таблицы
- поля
- типы
- связи
- индексы
- ограничения
- nullable / not null
- default values

И желательно:

- SQL создания таблиц
- примеры данных
- правила миграций

Без этого AI будет постоянно “догадываться”, как устроена БД.
