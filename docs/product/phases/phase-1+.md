# Phase 1 — HTML-прототипы: Каталог, Объект, Избранное

## Задача
Создать статичные HTML-прототипы четырёх экранов сервиса аренды домов DOMIKTUT.RU:
- Каталог домов (`/catalog`)
- Попап / панель фильтров каталога
- Страница отдельного объекта (`/house`)
- Страница избранного (`/favorites`)

Референсы: `docs/design-refs/` и `docs/product/design-direction+.md`

---

## Design Direction

### Общий стиль
Чистый, профессиональный, светлый интерфейс. Минимум декора — максимум читаемости. Оранжевый акцент привлекает внимание к действиям (бронирование, поиск). Тёмный хедер и футер создают обрамление, всё содержимое на белом/светлом фоне.

### Референсы
- `docs/design-refs/catalog page.jpg` — каталог со split view (список + карта)
- `docs/design-refs/house page.jpg` — страница объекта с галереей и формой бронирования
- `docs/design-refs/favorite page.jpg` — список избранного с горизонтальными карточками
- `docs/design-refs/pop up filter.png` — попап фильтров
- `docs/design-refs/main page.jpg` — хедер, карточки, футер

### Что нравится в референсах
- Split view каталога (список + карта рядом) — наглядно и функционально
- Горизонтальные карточки с иконками характеристик — компактно и информативно
- Галерея объекта (1 большое + 4 превью) — стандарт для недвижимости
- Форма бронирования справа от описания — sticky, всегда доступна
- Чёткая иерархия цен (будни / выходные / праздники)

### Что НЕ нравится (не делать)
- Glassmorphism
- Сложные анимации и переходы
- Перегруженные градиенты на карточках
- Мелкий текст в характеристиках
- Слишком плотные списки без воздуха

## Типографика

- **Шрифт:** `Inter`, fallback — `system-ui, sans-serif`
- **H1 (заголовок страницы):** 28px, weight 700
- **H2 (секции):** 22px, weight 700
- **H3 (название карточки):** 16px, weight 600
- **Body:** 14px, weight 400, line-height 1.5
- **Мелкий текст / метки:** 12px, color: `#6B6B6B`
- **Цена акцентная:** 18px, weight 700, color: `#E8530A`

---

## UI принципы

- Крупные читаемые кнопки (min-height: 44px, padding: 10px 24px)
- Чёткие поля форм с видимым border и focus-состоянием
- Карточки с лёгкой тенью `0 2px 12px rgba(0,0,0,0.10)`, border-radius: 12px
- Hover на карточках: `transform: translateY(-2px)`, усиление тени
- Hover на кнопках: потемнение цвета на 10%
- Иконки inline SVG, outline-стиль, 18–20px

---

## Ограничения

- Без UI-библиотек (Bootstrap, Tailwind и т.д.)
- Без CSS-фреймворков
- Без JS-фреймворков — максимум vanilla JS
- Без внешних шрифтов (кроме Google Fonts Inter)
- Без сложных анимаций
- Статичные HTML-файлы — данные захардкожены в HTML

## Экраны фазы 1

### 1. Каталог (`catalog.html`)
- Хедер: логотип, город, навигация, избранное, телефон
- Панель фильтров: горизонтальная, sticky — чипы (Цена, Дата, С бассейном, Развлечения, Кол-во мест, Подборки) + кнопка "Найти на подбор" (оранжевая) + иконка "Фильтр"
- Split view: 45% список / 55% карта-заглушка (серый блок с текстом "Карта")
- Список: 4–5 горизонтальных карточек с фото, названием, адресом, иконками характеристик, ценами, кнопкой "Подробнее"
- Футер

### 2. Попап фильтров (внутри `catalog.html`)
- Триггер: кнопка "Фильтр" в панели каталога
- Оверлей + белый попап (border-radius: 16px, тень)
- Заголовок "Фильтры" + крестик закрытия
- Секции: ценовой диапазон (два инпута), удобства (чекбоксы: бассейн, баня, сауна), кол-во мест (инпут или степпер)
- Кнопки внизу: "Сбросить" (ghost/outline) + "Применить" (оранжевая)

### 3. Страница объекта (`house.html`)
- Хедер
- Breadcrumb: Главная › Каталог › Горки-Сухаревские 1
- Галерея: крупное фото (65%) + 2×2 превью (35%) — все заглушки
- Левая колонка: название H1, адрес, характеристики иконками, описание, доп. услуги, раздел "Расположение" (видео-заглушка + карта-заглушка), "Отзывы" (3 карточки)
- Правая колонка (sticky): форма бронирования — таблица цен (будни / выходные / праздники), итоговая цена, кнопка "Забронировать" (оранжевая, полная ширина), ссылка "Задать вопрос"
- Футер

### 4. Избранное (`favorites.html`)
- Хедер
- Заголовок страницы "Избранное" H1
- Список горизонтальных карточек (4 штуки) — аналогичны карточкам каталога
- Пустое состояние (если нет избранного): иконка + текст "Вы ещё ничего не добавили"
- Футер
