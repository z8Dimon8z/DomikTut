# Phase 2 — JS-интерактивность прототипов

## Задача
Добавить клиентскую интерактивность ко всем HTML-прототипам из Phase 1. Каждая страница получает свой JS-файл. Общая логика выносится в `js/main.js`.

Ни один JS-файл не использует фреймворки или библиотеки — только vanilla JS.

---

## Файловая структура

```
prototypes/phase-1/
  js/
    main.js        — общая логика: избранное (localStorage), мобильное меню
    index.js       — главная: аккордеон FAQ, переключение hero-превью
    catalog.js     — каталог: попап фильтров, чипы фильтров, ховер пинов карты
    house.js       — объект: галерея, расчёт стоимости, sticky booking-card
    favorites.js   — избранное: удаление из избранного
```

---

## main.js — общая логика (все страницы)

### 1. Система избранного (localStorage)
- Хранит массив ID объектов в `localStorage` под ключом `domik_favorites`
- `Favorites.toggle(id)` — добавить / убрать из избранного
- `Favorites.has(id)` — проверить наличие
- `Favorites.getAll()` — получить весь список
- При загрузке страницы — синхронизировать состояние всех кнопок `.card-h__fav` и `.card-v__fav` с localStorage
- Обновлять счётчик `.header__favorite-count` на всех страницах

### 2. Мобильное меню
- Бургер-кнопка в хедере на мобайле (< 768px)
- Клик открывает / закрывает `.nav` (slide-down или toggle класс `is-open`)
- Клик вне меню — закрыть

## index.js — главная страница

### 1. Аккордеон FAQ
- Клик на `.faq-item__question` → toggle класса `is-open` на родительском `.faq-item`
- Только один пункт открыт одновременно
- Анимация раскрытия через `max-height` CSS-переход

### 2. Переключение hero-превью
- Клик на `.hero__thumb` → добавить класс `--active`, убрать у остальных
- Смена фона `.hero__bg` (в прототипе — смена CSS gradient-цвета)

## catalog.js — каталог

### 1. Попап фильтров
- `#openFilter` → открыть `#filterOverlay` (класс `is-open`)
- `#closeFilter`, `#applyFilter` → закрыть попап
- Клик на оверлей (вне `.modal`) → закрыть
- `#resetFilter` → сбросить все чекбоксы и степпер

### 2. Степпер количества мест
- `#stpMinus` / `#stpPlus` → декремент / инкремент значения `#stpVal`
- Минимум: 1, максимум: 50

### 3. Чипы фильтров
- Клик на `.filter-chip` → toggle класса `filter-chip--active`
- Клик на активный чип — деактивировать

### 4. Ховер пинов карты
- Наведение на `.map-pin` → добавить класс `map-pin--active`, убрать у остальных
- Одновременно подсветить соответствующую карточку в списке (добавить `card--highlighted`)

## house.js — страница объекта

### 1. Переключение галереи
- Клик на `.gallery__thumb` → сменить фон `.gallery__main` на цвет / фото этого превью
- Добавить класс `gallery__thumb--active` на кликнутый превью, убрать у остальных

### 2. Расчёт стоимости бронирования
- При изменении дат заезда/выезда в форме бронирования:
  - Вычислить количество суток
  - Определить тип дней (будни / выходные) по дням недели
  - Обновить итоговую сумму в `.booking-total__value`
  - Обновить надпись "за N суток" в `.booking-total__label`
- Валидация: дата выезда не может быть раньше или равна дате заезда

### 3. Sticky booking-card на мобайле
- На ширине < 768px: кнопка "Забронировать" фиксируется внизу экрана при скролле
- При скролле к форме — убрать фиксацию

### 4. Лайтбокс галереи (опционально)
- Клик на `.gallery__main` → открыть полноэкранный просмотр фото
- Закрытие по клику или клавише Escape

## favorites.js — страница избранного

### 1. Удаление из избранного
- Клик на `.card-h__fav--active` → убрать ID из localStorage
- Анимация исчезновения карточки: `opacity 0.2s → height 0s`
- Если список пустой → показать `.favorites-empty` (скрытый по умолчанию)
- Обновить счётчик в заголовке и в `.header__favorite-count`

### 2. Синхронизация счётчика
- При загрузке страницы — показать актуальное количество из localStorage
- Обновить текст `.favorites-count`

## Design Constraints для JS

- Только vanilla JS, без jQuery и других библиотек
- Никаких `document.write`
- Все обработчики — через `addEventListener`
- Не менять стили напрямую через `.style.*` — только добавлять / убирать CSS-классы
- Исключение: `max-height` для анимации аккордеона и расчётные числа в тексте
- Код разбит на функции, не один большой блок
