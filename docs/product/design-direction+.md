# Design Direction — DOMIKTUT.RU

> Руководство для создания HTML-прототипов. Описание основано на дизайн-референсах из `docs/design-refs/`.

---

## 1. Суть продукта

Сервис аренды коттеджей и загородных домов в Казани и окрестностях. Целевая аудитория — семьи и компании, ищущие дом для отдыха на выходные или праздники. Акцент на доверие, удобный поиск и прозрачное ценообразование.

---

## 2. Брендинг

- **Название:** DOMIKTUT.RU
- **Логотип:** иконка домика + текст "DOMIKTUT.RU", оранжевый цвет
- **Тон:** дружелюбный, понятный, без лишнего официоза

---

## 3. Цветовая палитра

| Роль | Цвет | Применение |
|---|---|---|
| Accent / Primary | `#E8530A` (оранжевый) | кнопки CTA, логотип, иконки цен, активные элементы |
| Dark BG | `#1A1A2E` (тёмно-синий/чёрный) | hero-секция главной, футер |
| Light BG | `#F5F5F5` (светло-серый) | фон страниц, фон секций |
| White | `#FFFFFF` | карточки, попапы, форма |
| Text Primary | `#1C1C1C` | заголовки, основной текст |
| Text Secondary | `#6B6B6B` | подписи, адреса, метки |
| Border | `#E0E0E0` | разделители, рамки инпутов |

---

## 4. Типографика

- **Шрифт:** системный sans-serif (Inter / Golos Text / или системный стек)
- **Заголовки страниц (H1):** 28–36px, font-weight: 700
- **Заголовки секций (H2):** 22–26px, font-weight: 700
- **Заголовки карточек (H3):** 16–18px, font-weight: 600
- **Body:** 14–15px, font-weight: 400, line-height: 1.5
- **Мелкий текст / метки:** 12–13px, color: text-secondary

---

## 5. Сетка и лейаут

- **Максимальная ширина контейнера:** 1200px, центрирован
- **Отступы контейнера:** 24px по бокам на мобайле, 40px на десктопе
- **Гриды:**
  - Карточки на главной: 4 колонки на десктопе, 2 на планшете, 1 на мобайле
  - Каталог: левая панель (список, ~45%) + правая (карта, ~55%), split view
  - Страница объекта: 2 колонки (контент + форма бронирования)
- **Gap между карточками:** 20–24px

---

## 6. Компоненты

### Header (шапка)
- Фиксированный, белый фон, тонкая тень снизу
- Слева: логотип + выбор города (выпадашка с иконкой геопина)
- По центру/справа: навигация (Каталог, Частые вопросы, Сотрудничество)
- Крайне справа: иконка сердечка (избранное), поиск по названию, телефон
- На мобайле: бургер-меню

### Hero-секция (только главная)
- Тёмный фон (фото загородного дома ночью с наложением тёмного оверлея)
- Крупный заголовок H1 белым цветом: "Аренда коттеджей и домов в Казани"
- Форма быстрого поиска поверх hero: поле даты заезда/выезда, кол-во гостей, кнопка "Найти" (оранжевая)
- Форма на белом фоне с тенью, скруглённые углы

### Карточка объекта (вертикальная — главная)
- Фото с соотношением 4:3, скруглённые верхние углы
- Иконка сердечка (избранное) в правом верхнем углу фото
- Под фото: название, краткие характеристики иконками, цена "от X ₽ / сутки"
- Тень: `box-shadow: 0 2px 12px rgba(0,0,0,0.10)`
- border-radius: 12px

### Карточка объекта (горизонтальная — каталог, избранное)
- Фото слева (фиксированная ширина ~200px), контент справа
- Фото: скруглённые левые углы
- Контент: название (H3), адрес (мелкий серый), характеристики иконками в строку (кол-во мест, баня, бассейн, сауна, развлечения), блок цен (будни / выходные / праздники), кнопка "Подробнее"
- Иконка избранного (сердечко) + иконка "до X мест" в правом верхнем углу
- border-radius: 12px

### Фильтры (панель каталога)
- Горизонтальная полоса под хедером
- Чипы/кнопки-фильтры: Цена, Дата, С бассейном, Развлечения, Кол-во спальных мест, Подборки
- Каждый фильтр — кнопка с border, при нажатии открывает дропдаун или попап
- Правая часть: кнопка "Найти на подбор" (оранжевая, primary) + иконка "Фильтр"

### Попап фильтров
- Белый фон, border-radius: 16px, тень
- Заголовок попапа, крестик закрытия
- Форма с чекбоксами / слайдерами / инпутами
- Кнопки "Сбросить" (ghost) и "Применить" (оранжевая)

### Форма бронирования (страница объекта)
- Плавающая карточка справа, белый фон, тень
- Блок цен: будни / выходные / праздники (таблица или список)
- Итоговая цена крупно
- Кнопка "Забронировать" (оранжевая, полная ширина)
- Ссылка "Задать вопрос"

### Секция "Частые вопросы"
- Аккордеон: вопрос + стрелка, при клике раскрывается ответ
- Разделители между пунктами
- Фон: белый или светло-серый

### CTA-блок (внизу главной)
- Тёмный фон (фото + overlay), крупный заголовок белым, подзаголовок, оранжевая кнопка
- "Готовы сдать дом?" — для привлечения владельцев

### Footer
- Тёмный фон (`#1A1A2E`)
- Логотип + слоган
- 3–4 колонки ссылок: Каталог (с подкатегориями), Сотрудничество, Частые вопросы
- Телефон, иконки соцсетей (ВК, Instagram, Telegram и др.)

## 8. Иконки и иллюстрации

- Используются простые моно-иконки (outline стиль) для характеристик объектов:
  - спальные места, баня, бассейн, сауна, настольный теннис, сауна, развлечения
- Иконки: SVG inline или иконочный шрифт (без внешних зависимостей в прототипе)
- Для категорий на главной — иконки + подпись под ними

---

## 9. Design Constraints (обязательно соблюдать)

- Без glassmorphism
- Без сложных CSS-анимаций (только простые hover: opacity, box-shadow, transform translateY(-2px))
- Без UI-библиотек (Bootstrap, Tailwind и т.д.) — чистый HTML + CSS
- Без JS-фреймворков в прототипах — максимум vanilla JS для базовой интерактивности
- Приоритет: читаемость, скорость загрузки, понятная структура
- Все размеры в px или rem, без vw/vh кроме высоты hero
- Карточки должны корректно отображаться без фото (заглушка серого цвета)

---

## 10. Адаптивность

| Брейкпоинт | Поведение |
|---|---|
| 1200px+ | Полный десктоп, max-width контейнера |
| 768–1199px | Планшет: каталог переходит в 1 колонку (список поверх карты или карта скрыта) |
| < 768px | Мобайл: всё в 1 колонку, хедер → бургер, фильтры → кнопка "Фильтры" открывает попап |
