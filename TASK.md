# Current Task

## Current phase
Phase 1

## Task
Создать статичные HTML-прототипы четырёх экранов сервиса аренды домов DOMIKTUT.RU: каталог, страница объекта, избранное, попап фильтров.

## Scope
- `prototypes/phase-1/catalog.html` — каталог с панелью фильтров и split view (список + карта)
- `prototypes/phase-1/house.html` — страница отдельного объекта с галереей и формой бронирования
- `prototypes/phase-1/favorites.html` — страница избранного со списком объектов
- `prototypes/phase-1/css/style.css` — общие стили для всех трёх страниц
- `prototypes/phase-1/css/catalog.css` — стили каталога и попапа фильтров
- `prototypes/phase-1/css/house.css` — стили страницы объекта
- `prototypes/phase-1/css/favorites.css` — стили страницы избранного

## Out of scope
- Серверная логика, PHP, база данных — это статичные прототипы
- Реальная карта (Яндекс.Карты / Google Maps) — достаточно заглушки
- Авторизация и личный кабинет
- Главная страница (`/`) — это Phase 2
- Форма бронирования с реальной отправкой — только визуал
- JavaScript-функциональность поиска и фильтрации — только открытие попапа фильтров

## Acceptance criteria
- `catalog.html` открывается без ошибок в браузере
- Панель фильтров отображается горизонтально под хедером, кнопка "Фильтр" открывает попап
- Попап фильтров появляется поверх контента, закрывается по крестику и по клику на оверлей
- Split view каталога: список карточек слева (~45%), карта-заглушка справа (~55%)
- Горизонтальные карточки содержат: фото, название, адрес, иконки характеристик, цены, кнопку "Подробнее"
- `house.html` открывается без ошибок в браузере
- Галерея объекта: 1 крупное фото + 4 превью в сетке 2×2
- Форма бронирования отображается справа от описания
- `favorites.html` открывается без ошибок в браузере
- Список избранного содержит горизонтальные карточки (аналог каталога)
- Хедер и футер одинаковы на всех трёх страницах
- Страницы адаптивны: на ширине < 768px каталог переходит в одну колонку
- Нет ошибок в консоли браузера
- Вёрстка соответствует дизайн-референсам из `docs/design-refs/`

## Important rules
- следовать `docs/product/design-direction+.md` — цвета, типографика, компоненты
- следовать `docs/product/phases/phase-1+.md` — детальное описание каждого экрана
- без UI-библиотек (Bootstrap, Tailwind и т.д.)
- без CSS-фреймворков и JS-фреймворков
- vanilla JS только для попапа фильтров (open/close)
- данные захардкожены в HTML — это прототип, не приложение
- не создавать файлы вне директории `prototypes/phase-1/`
- оранжевый акцент `#E8530A`, тёмный хедер/футер `#1A1A2E`, белые карточки с тенью
- шрифт Inter (подключить через Google Fonts)
